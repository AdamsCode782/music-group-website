# Music Group Website

A modern, responsive website for a music artist designed to showcase media, tour dates, and booking information. This project focuses on high-performance UI and seamless cross-device compatibility.

## ✨ Key Features

- **Responsive Media Gallery:** Optimized for high-resolution band photography and video content.
- **Tour Management UI:** Clean, scannable interface for upcoming shows and ticket links.
- **Booking Integration:** Functional contact and booking section for professional inquiries.
- **Utility-First Styling:** Built with Tailwind CSS for rapid, maintainable UI development.

## 🛠 Tech Stack

| Category | Tools |
| :--- | :--- |
| **Frontend** | HTML5, JavaScript (ES6+) |
| **Styling** | Tailwind CSS |
| **Build Tool** | Live-Server |

## 🚀 Getting Started

### Installation

1. **Clone the repository:**
 ```bash
git clone https://github.com/AdamsCode782/music-group-website.git
cd music-group-website
```

2. **Install dependencies:**
```bash
npm install
```

3. **Build & Run:**
Compile the Tailwind CSS and start the local server:
```bash
npm run compile
npm start
```
